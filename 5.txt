# Minecraft Forge Mod 玩家卡住机制实现提示词

## 功能描述
实现一个玩家卡住机制，用于在特定条件下（如高速移动时）冻结玩家行为，执行批量操作（如放置方块），然后根据释放条件自动恢复玩家正常状态。

## 核心实现原理

### 1. 卡住状态管理
- 使用静态变量 `playerStuckTicks` 管理卡住状态，初始值为0
- 当 `playerStuckTicks > 0` 时，玩家处于卡住状态
- 每游戏刻递增计数器，达到阈值后自动释放

### 2. 卡住行为实现
- 使用 Mixin 注入玩家 Tick 事件
- 当检测到 `playerStuckTicks > 0` 时，取消玩家 Tick 事件，冻结玩家行为
- 保留必要的系统功能，如方块放置、网络通信等

### 3. 释放条件检测
- 每游戏刻检查释放条件
- 满足任一条件即释放玩家：
  - 卡住时间超过阈值
  - 玩家脚下有方块
  - 正脚下有方块（射线检测）
  - 手动触发释放

### 4. 批量操作执行
- 在卡住状态下，执行批量操作（如放置方块）
- 确保操作使用正确的旋转角度
- 执行完操作后检查释放条件

@Mixin({Player.class})
public abstract class MixinPlayer extends LivingEntity {
    @Inject(
        method = {"tick"},
        at = {@At("HEAD")},
        cancellable = true

    private void onTick(CallbackInfo ci) {
        if (PlayerUtils.playerStuckTicks > 0) {
            if (PlayerUtils.useAutoDecrementClose) {
                // 自动递减逻辑
                PlayerUtils.playerStuckTicks--;
                ci.cancel();
            } else {
                // 传统关闭逻辑
                if (PlayerUtils.playerStuckTicks > 15 || PlayerUtils.hasBlockUnderFeet() || PlayerUtils.isBlockBelowInRange()) {
                    PlayerUtils.playerStuckTicks = 0;
                } else {
                    ci.cancel(); // 冻结玩家行为
                }
            }
        }
    }
}

## 关键技术点

### 1. Mixin注入
- 使用 `@Inject` 注入玩家 `tick` 方法
- 使用 `cancellable = true` 允许取消事件
- 在 `@At("HEAD")` 位置注入，确保优先执行

### 2. 旋转角度处理
- 保存并恢复玩家原始旋转角度
- 为每个操作计算正确的旋转角度
- 确保操作使用的旋转角度与网络数据包一致

### 3. 释放条件优先级
- 脚下有方块 > 正脚下有方块 > 超时检测
- 确保释放条件覆盖所有可能情况
- 避免永久卡住

### 4. 性能优化
- 减少不必要的计算
- 限制检测范围
- 优化射线检测性能

## 注意事项

### 1. 避免永久卡住
- 设置合理的超时阈值
- 确保至少有一个可靠的释放条件
- 添加紧急释放机制

### 2. 与其他模块兼容
