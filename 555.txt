   **源代码实现 - MixinClientPlayerEntity.java** (`MixinClientPlayerEntity.java:53-63`)：
   ```java
   @Inject(method = "tick", at = @At(value = "INVOKE",
       target = "Lnet/minecraft/client/network/AbstractClientPlayerEntity;tick()V",
       shift = At.Shift.BEFORE,
       ordinal = 0),
       cancellable = true)
   private void hookTickEvent(CallbackInfo ci) {
       var tickEvent = Client.EVENT_BUS.post(PlayerTickEvent.get());

       if (tickEvent.isCancelled()) ci.cancel();

       if (PlayerUtils.playerStuckTicks > 0) {
           PlayerUtils.playerStuckTicks--;
           ci.cancel();
       }
   }
   ```

   **源代码实现 - MixinClientWorld.java** (`MixinClientWorld.java:29-38`)：
   ```java
   @Redirect(method={"tickEntity"}, at=@At(value="INVOKE", target="Lnet/minecraft/entity/Entity;tick()V"))
   public void hookSkipTicks(Entity instance) {
       if(PlayerUtils.playerStuckTicks > 0 && instance.equals(mc.player)) {
           PlayerUtils.playerStuckTicks--;
           if(PlayerUtils.playerStuckTicks > 20){
               PlayerUtils.playerStuckTicks = 20;
           }
       }
       else instance.tick();
   }
   ```
   - **MixinClientPlayerEntity.java**：在玩家tick事件头部注入，每刻递减playerStuckTicks并取消tick事件
   - **MixinClientWorld.java**：在世界实体tick事件中重定向调用，再次递减playerStuckTicks
   - 每刻总共递减2，确保快速解除卡住状态
   - 设置最大值限制：当playerStuckTicks > 20时，自动设为20
